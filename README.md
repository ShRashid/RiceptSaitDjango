# Django - Проект “Сайт рецептов”

Этот проект представляет собой веб-приложение, предназначенное для хранения и просмотра рецептов. 
Пользователи имеют возможность добавлять, просматривать, редактировать и удалять свои рецепты, а 
также исследовать рецепты, созданные другими пользователями.

## Установка
1. Клонируйте репозиторий на ваш ПК :

    ```bash
    git clone https://github.com/ShRashid/RiceptSaitDjango.git
    ```

2. Далее установите зависимости:

    ```bash
    pip install -r requirements.txt
    ```

3. Затем настройте соединение с базой данных в файле settings.py:

   
   ```python
   DATABASES = {
     'default': {
         'ENGINE': 'django.db.backends.sqlite3',
         'NAME': BASE_DIR / 'db.sqlite3',
     }
   }
   ```
   
4. Выполните миграции базы данных:

    ```bash
    python manage.py migrate
    ```

5. Создайте суперпользователя:

    ```bash
    python manage.py createsuperuser
    ```

6. Далее можно запустить сервер разработки Django:

    ```bash
    python manage.py runserver
    ```

7. После успешного запуска сервера, перейдите  по адресу http://localhost:8000/, чтобы начать работу с приложением.

## Используемые Функции

- Регистрация и аутентификация пользователей
- Просмотр главной страницы с 5 случайными рецептами кратко
- Добавление, редактирование и удаление рецептов
- Просмотр подробной информации о рецепте
- Категоризация рецептов
- Возможность добавления изображения для рецепта


## Используемые Технологии

- Python
- Django - фреймворк для разработки веб-приложений
- SQLite - СУБД для хранения данных
- HTML/CSS - для создания пользовательского интерфейса
- JavaScript - для добавления интерактивности и динамического поведения
